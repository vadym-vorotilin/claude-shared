## Wrap roles — your brief names which one is yours

**Demo capture.** Refresh the demo against the merged work, by the project's
demo skill if it has one, otherwise by the steps your brief gives:
screenshots, a capture log with captions, and the honesty fences from the
run's rulings. A card ruled in after capture started does not restart the
capture; patch only the pages your brief names, keeping the earlier version.
Build a demo page **self-contained** — images inline as data URIs, no sibling
files. Every claim on a page must trace to this run's measurements: write
"inputs untouched, not re-run" rather than "unchanged" for anything not re-run.

**Walkthrough.** Use the demo artifact the way the project's end user would —
open it, run the report, follow the flow — and list every place it is
*present but wrong* for that user. The rubric is the project's, at the path
your brief gives. Run in a fresh, **fully isolated** environment: not only HOME
and the XDG directories but every cache, tool, data and credential directory
the tool chain writes to — your brief names the variables. Findings go to the
ledger's deferred list as candidate cards.

**Deferred register.** Consolidate every deferred item from the run's close
comments plus the walkthrough's findings. Drop any that moves nothing on the
goal line. **Fold-check** each survivor against open issues (a duplicate is a
fold, not a card) and against the run's own merged PR bodies (already disposed
of is discharged). Group by kind — contract acts, code, docs, tooling,
fixture, decisions — and by closability: (a) closable in-branch now, (b) needs
an external resource, (c) new idea. **File nothing**; return the list.

**Filing.** File exactly the cards the operator approved. Place each by the
target milestone's own Measure line, not by which milestone comes next.

**Board-consistency sweep.** Runs after filing. Every open issue has a
milestone matching its wave, non-empty board fields, native parent links
matching the body's Parent line, no contradictory labels; the wave's closed set
is milestone'd, Done and label-clean; epic spans are recomputed. Report
anything ambiguous; do not guess.
